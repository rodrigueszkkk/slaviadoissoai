- [ ] Task criada, atribuída a você, **Active**, e **relacionada** à branch/commits/PR (−1)
- [ ] **Duas coleções com relacionamento** (Grupos ↔ Trabalhos por `grupoId`) (−2)
- [ ] `main` com políticas: 1 revisor, work item obrigatório, revisor padrão (−2)
- [ ] PR criada e aprovada por você; branch **não deletada**; Task fechada (−1)
- [ ] CI executa **testes** (aba Tests visível) (−2)
- [ ] Alteração em **código** (Trabalho.cs, testes, Program.cs), não em README (−2)
- [ ] Scripts de infra via CLI (`infra/01..03`) (−1 por script ausente)
- [ ] Variáveis de ambiente + segredos protegidos (cadeado na Pipeline; nada de senha no repo) (−1)
- [ ] Recursos criados pelos scripts **mostrados no Portal** (−1)
- [ ] CRUD das duas coleções comprovado por **SELECT no banco** (−3)
- [ ] `pf0841@fiap.com.br` como Project Administrator + Basic na organização (sem isso, não corrige)
- [ ] PDF `<nomeGrupo>_pipelines.pdf` com folha de rosto, link do projeto e do vídeo (−0,5)
- [ ] `script.sql` no Repos (−1)
- [ ] Código-fonte completo + vídeo (sem isso, não corrige)
- [ ] `Dockerfile` e `docker-compose.yml` no Repos (−4 se faltar e usar container)
- [ ] `azure-pipeline.yml` e JSONs do CRUD (`json-crud/`) no Repos
- [ ] Vídeo ≥ 720p, narrado, sem cortes (−3)
- [ ] Entrega no Teams **antes do prazo** (−3 pontos por hora de atraso, tolerância máx. 2h) – só o representante envia
